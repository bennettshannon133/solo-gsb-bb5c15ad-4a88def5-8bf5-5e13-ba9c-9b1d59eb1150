# 博物馆展签排版工具（Museum Label Typesetter）

一个用于排版博物馆展签的 Web 工具：输入标题、中文说明文字、可选的**英文译文**
与展签物理尺寸（毫米），浏览器实时预览，并可直接打印或导出为与预览**同换行、同物理尺寸**的 PDF；
除单张打印外，还支持把同一成品按份数**拼版到 A4 纸**一次打印多张，
以及把 CSV 校样通过的不同记录按原顺序**异款批量拼版**到 A4 一次打印。

- 填写英文译文即进入**中英对照双栏模式**：标题横跨整签，中文原文与译文左右并列；译文留空保持单栏
- 可选**中英段落对齐**（仅双栏）：开启后中英正文按换行拆成非空段落、按顺序一一配对，
  每对仍按现有栏宽/保护词/标点规则各自独立断行，但**下一对在两栏同一高度起始**
  （段对高度取双方较高者，段对之间沿用现有段间距）；字号按全部段对高度总和连同标题与
  二维码预留区一起核算，12px 仍超高则报错禁印。两侧**段数不一致**时会指出中文/英文各几段
  并禁用当前成品打印；关闭开关即恢复现有独立双栏
- 可选**展品介绍二维码**：填写 `https://` 开头的链接（UTF-8 不超过 100 字节）后，二维码在浏览器
  **本地生成**（不依赖任何外部二维码服务）；展签底部固定留出 22mm 区域，18mm 码图居中、
  四周保留至少 2mm 空白；排版先扣除该区域再选字号；留空链接即恢复原版式
- 可选**中文修订对照**：填写不超过 300 字的修订稿后，按 Unicode 字符求最短增删对齐并标出新增/删除片段；
  原稿与修订稿分别按当前尺寸与英文译文排版，对比字号、中文行数与能否容纳；选定一版作为成品，
  差异标记只在屏幕上显示，不进入打印
- 可选**双语术语核对**：侧栏逐行录入「中文术语=英文译名」对照表（空行忽略；重复中文项、
  空值或格式错误逐行提示）。开启中英段落对齐且两侧段数一致后，对当前选定成品（原稿或修订稿）
  逐段核对：中文术语按最长优先匹配、命中区间不重复计数，英文译名忽略大小写并按完整词组边界计数；
  任一术语在某段中英两侧次数不符时列出段号、术语及两侧次数，并禁用单张与拼版打印，修正后恢复
- 可选**中文专名保护表**：每行一个不可断行的中文专名（最多 20 个、每个 1～12 个 Unicode 字符），
  标题与中文正文按「最长优先、同长按录入顺序、不重叠」识别；命中区间**不切分任何词**，
  而是与原英文单词本身的不可断约束共同生效——部分重叠（如英文词中夹中保护词）或跨词命中
  都不会新增单词内部断点，命中覆盖的不可断整体在 12px 仍超宽时显示该整体与所需宽度并禁用打印，
  不拆词、不截断；标点避头尾按不可断整体的实际首/尾字符判断，内部括号不妨碍合法断点；
  原稿与修订稿共用同一张表；英文译文栏不套用专名表
- **同款展签拼版打印**：设置份数（1～100）与 A4 纵向/横向后，仅当所选成品（原稿或修订稿）
  通过排版校验，才把同一成品按原毫米尺寸逐页拼满 A4（每边留白 10mm、展签间隔 4mm、不缩放）；
  分页预览展示每页每张位置，拼版打印只输出拼版页；任一方向连一张都放不下时提示
  展签尺寸与纸内可用尺寸并禁用拼版打印；各份换行与二维码码图与单张预览完全一致
- 可选**库存规格选型**：逐行录入最多 12 种现有展签规格（宽×高，毫米；空行忽略、重复规格
  自动去重、非法行指出行号且不参与推荐），点击「选型」后以当前选定的成品版本
  （原稿或修订稿）与中英、段落对齐、专名保护、二维码设置，对每种规格调用同一套
  排版规则求最大可用字号；能完整容纳的规格按面积从小到大（同面积按录入顺序）推荐，
  失败规格注明原因；没有可用规格时明确提示且不改当前尺寸，点击「采用」才回填宽高
  并刷新预览、单张及拼版打印
- 可选**批量校样**：粘贴含表头 `title,zh,en` 的 CSV（最多 20 条；字段可用英文双引号
  包裹以包含逗号与换行，字段内双引号写两个），逐条校验列数与必填的标题、中文正文
  （错误定位到记录号）；每条仅替换标题、中文正文与英文译文，沿用当前尺寸、段落对齐、
  专名保护、二维码与术语表设置调用同一套排版及打印门禁，逐条列出可用字号或失败原因；
  校样不改变当前成品，点击通过记录的「载入编辑」才回填三栏并清空修订稿，
  随后由原有预览与打印流程处理
- **异款批量拼版打印**：沿用「批量校样」的 CSV 入口，点击「开始校样」后，通过校验的
  不同记录按原顺序逐条调用现有排版与打印门禁独立生成展签（中英、段落对齐、专名保护、
  术语核对与二维码均沿用当前设置），失败记录列出原因且不进入拼版；通过记录按当前
  展签毫米尺寸、纸张方向、每边 10mm 留白与 4mm 间隔逐页拼入 A4，页面预览与打印
  逐格对应，每张展签保留自己的换行与码图；单页连一张都放不下时禁用打印并说明尺寸
- 可选**馆藏号对账**：沿用批量校样 CSV 的额外 `accession` 列（对账时各记录必填）
  与另行粘贴的馆藏登记清单（每行一项）核对；号码为「年份.批次.三位流水号」
  （如 `2024.03.001`），支持同前缀闭区间（`2024.03.001-005`，展开保留三位宽度）；
  格式错误、区间倒序或任一侧展开超过 200 个号码即拒绝并指出来源行；按展开后的
  完整号码列出两侧各自的重号（含号段交叠）与仅在单侧出现的号码及来源行，
  顺序不同不算差异；对账只读，不改变校样、拼版与打印，任一输入变化即清空旧结果
- 后端：Node.js + Express（仅提供静态页面）
- 前端：原生 JavaScript / CSS，无构建步骤、无前端框架
- 排版算法：按 Canvas **实际字宽**逐字/逐词测量 + 动态规划断行
- 二维码：自包含 QR 编码器（字节模式、纠错等级 M、版本 1～10 自动选择、掩码自动择优）
- 无数据库、无第三方账号、无外部 API

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

然后浏览器打开：

```
http://localhost:3000
```

首次启动会在容器内自动执行 `npm install`（依赖随启动安装，不预装在镜像中），稍等数秒即可。

> 如果本机使用的是独立 `docker`（无 Compose 子命令）：
>
> ```bash
> docker build -t museum-label-typesetter .
> docker run --rm -p 3000:3000 museum-label-typesetter
> ```

## 不用 Docker 的本地运行方式

需要 Node.js ≥ 18。

```bash
npm install        # 安装唯一运行时依赖 express
npm start
```

访问 http://localhost:3000 。

## 必要配置（环境变量）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务监听端口。改端口：宿主机侧改 `docker-compose.yml` 的 `"3000:3000"` 左侧；容器内监听改环境变量 `PORT` 并同步右侧。 |
| `HOST` | `0.0.0.0` | 监听地址，容器内保持默认即可。 |

例如用本机 8080 端口：

```bash
PORT=8080 npm start                     # 本地直跑
docker run --rm -p 8080:3000 museum-label-typesetter   # Docker
```

## 使用方法

1. 左侧输入**标题**与**中文说明文字**（正文内回车可分段；中文里可直接夹 English 单词）。
2. 如需中英对照，在**英文译文**框填写译文（同样支持回车分段）：
   - **填写译文** → 双栏模式：标题横跨整签，中文原文与译文在正文区左右并列，栏间距固定 6mm；
   - **译文留空（或仅空白字符）** → 保持现有单栏排版。
   - 双栏时可勾选 **「中英段落对齐」**：中英正文先按回车拆成非空段落并按顺序一一配对；
     每对仍按各自栏宽与保护词、标点规则**独立断行**，但下一对在两栏**同一高度**起始，
     段对高度取双方较高者，段对之间沿用现有段间距；字号搜索按**段对高度总和**连同标题与
     二维码预留区核算，12px 仍超高时报错禁印。两侧**段数不等**时状态栏给出两侧段数差异
     （如「中文 3 段、英文 2 段」）并禁用打印，预览不生成成品；取消勾选即恢复独立双栏。
3. 可选：在**双语术语对照表**中逐行录入术语对照，格式为每行一条 **`中文术语=英文译名`**
   （分隔符半角 `=` 或全角 `＝` 均可，按第一个分隔符拆分，两侧空白可省略）：
   - **空行忽略**；**重复中文项**、**中文术语或英文译名为空**、**缺少 `=` 的格式错误**
     都会在输入框下方**逐行指出行号**，存在任一错误即对照表无效并禁用单张与拼版打印；
   - 核对仅在**开启「中英段落对齐」且中英段数一致**时进行，对象是**当前选定成品**
     （原稿或修订稿）的中文正文与共用的英文译文，按段落一一配对逐段比较；
   - 中文术语在每段内**从左到右、最长优先**匹配，命中区间不再参与后续匹配（不重复计数）；
     英文译名**忽略大小写**，按**完整词组边界**计数（命中两侧不得紧邻字母/数字/词内连字符）；
   - 任一术语在某段中英两侧**出现次数不符**时，「双语术语核对」区列出**段号、术语及两侧次数**，
     并禁用单张与拼版打印；编辑正文/译文/对照表或切换成品版本后自动重新核对，修正后即恢复；
   - 未开启段落对齐或段数不一致时只提示不核对（段数不一致本身已按第 2 条禁印）。
4. 可选：在**中文专名保护表**中每行填写一个需要整体保行的专名（如地名、人名、器名）：
   - 最多 **20** 个词，每个词 **1～12 个 Unicode 字符**；**空行忽略、重复词自动去重**；
   - 某行含换行以外的空白（空格、制表符、全角空格等，含仅空白的行）会报错并禁用打印；
   - 标题与中文正文在**每个段落内从左到右**识别：同一位置优先最长词、同长按录入顺序，
     已匹配字符不再参与后续匹配；命中词内部**不可断行**，词边界仍遵守标点避头尾规则；
   - 英文译文不参与保护；**原稿与修订稿分别应用同一张保护表**；编辑后实时重排；
   - 保护词在 **12px** 仍超出行/栏宽时，错误信息给出该词及所需毫米宽度并禁用打印，不拆词或截断。
5. 可选：在**展品介绍链接**框填写链接，展签底部将生成展品介绍二维码：
   - 链接须以 **`https://`** 开头（完整 URL，含主机名），**不含空白或控制字符**，
     **UTF-8 编码不超过 100 字节**（输入框下方实时显示字节数）；
   - 二维码在**浏览器本地生成**，不向任何外部二维码服务发送链接；
   - 展签**底部固定留出 22mm 区域**，18mm 码图水平居中，码图四周保留至少 2mm 空白；
     排版会**先扣除这 22mm** 再按现有规则为标题与单/双栏正文选最大可容纳字号，
     原稿与修订稿各自重新核算；所选版本因此放不下时提示**超高**并禁用打印；
   - **留空链接即恢复原版式**（不预留底部区域）；链接非法或无法编码时明确报错并禁用打印。
6. 可选：在**修订稿**框输入修订后的中文正文（不超过 300 字，超出自动截断）：
   - 对照区按 Unicode 字符求**最短增删对齐**（同代价时固定优先保留原文较早字符），
     绿色为新增、红色删除线为已删，段落的增删以 ↵ 标记；
   - 原稿与修订稿沿用当前尺寸与英文译文**分别排版**，对照表列出两版正文字号、中文行数与能否容纳及其变化；
   - 在「成品版本」中选择原稿或修订稿：右侧预览与打印只显示所选版，差异标记不进入打印；
   - 所选版排不下时对照区保留，状态与预览说明**超宽或超高**，打印按钮禁用；
   - 清空修订稿即恢复原有单稿模式。
7. 输入展签**宽度 / 高度（毫米）**，合法范围 30–999mm × 20–999mm，内边距固定 8mm。
8. 可选：在**库存规格选型**区逐行录入现有展签的「宽×高」（毫米，宽 30～999、高 20～999，最多 12 种）：
   - **空行忽略、重复规格自动去重**；非法行（格式不符或宽高超出范围）会**指出行号**且不参与推荐；
   - 点击「**选型**」：以当前选定的成品版本（原稿或修订稿）与当前中英、段落对齐、
     专名保护、二维码设置，对每种规格调用现有排版规则求**最大可用字号**；
   - 结果中**能完整容纳的规格按面积从小到大**（同面积按录入顺序）列在前面并给出可用字号，
     其余规格注明失败原因；**没有可用规格时明确提示，当前尺寸不变**；
   - 点击某行的「**采用**」才把该规格回填到宽/高输入，并刷新原有预览、单张及拼版打印；
     修改文案或设置后请重新点击「选型」。
9. 可选：在**批量校样**区粘贴含表头 `title,zh,en` 的 CSV 并点击「**开始校样**」：
   - 最多 **20 条**数据记录（不含表头）；字段可用**英文双引号整体包裹**以包含逗号、
     换行，字段内的双引号写两个（`""`）转义；行尾支持 LF/CRLF/CR，完全空白的行忽略；
   - 逐条校验**列数**（须与表头列数一致）与**必填**的标题（title）、中文正文（zh），
     错误**定位到记录号**（从 1 起、不含表头）；英文译文（en）可空，留空的记录按单栏试排；
   - 每条记录**仅替换标题、中文正文与英文译文**，沿用当前尺寸、段落对齐开关、
     专名保护表、二维码链接与术语对照表设置，调用与成品相同的排版规则与打印门禁
     （含段落数一致、术语次数核对）逐条试排；
   - 结果表逐条列出**可用字号**（✓）或**失败原因**（✗ 列数/必填、超宽、超高、
     段数不一致、术语核对未通过等）；当前链接、保护表、术语表或尺寸存在阻塞性错误时，
     需先修正当前设置才能校样；
   - **校样不改变当前成品**；点击通过记录的「**载入编辑**」才回填标题、中文正文与
     英文译文三栏并**清空修订稿**，随后由原有预览、单张打印与拼版打印流程处理。
10. 可选：**异款批量拼版打印**（沿用第 9 步的 CSV 校样入口）：
   - 点击「开始校样」后，通过校验的不同记录按 CSV 原顺序各自调用现有排版与打印门禁
     独立生成展签（中英、段落对齐、专名保护、术语核对、二维码均沿用当前设置），
     每张展签保留自己的换行与码图；失败记录在校样结果中列出原因，**不进入拼版**；
   - 分页按**当前展签毫米尺寸**与「同款拼版」区的 **A4 纵向/横向**选择计算：
     每边留白 10mm、展签间隔 4mm、不缩放；切换纸张方向即按新方向重新分页；
   - 右侧「异款批量拼版预览」**分页展示每页每张展签的位置**（页码与本页张数见每页下方标注），
     与打印输出逐格对应；
   - 单页连一张展签都放不下时，提示**展签尺寸与纸内可用尺寸**并禁用异款拼版打印，
     可切换纸张方向或缩小展签尺寸后重新校样；
   - 修改尺寸、段落对齐、专名、术语、二维码或 CSV 后拼版失效，需重新点击「开始校样」；
   - 点击「异款拼版打印 / 导出 PDF」：打印**只输出异款拼版页**（不含编辑面板、单张预览
     与同款拼版预览），纸张已自动设为 A4 对应方向，边距选「无」、缩放 100% 即可。
11. 可选：在**馆藏号对账**区粘贴馆藏登记清单（每行一项）并点击「**开始对账**」：
   - 对账沿用「批量校样」的 CSV：表头须含 **accession** 列（列名去首尾空白、
     忽略大小写，顺序任意），且每条记录的 accession **非空**；列数不符或号码为空的
     记录会指出记录号并中止对账；
   - 号码格式为「**年份.批次.三位流水号**」（如 `2024.03.001`）；同前缀闭区间
     写作 `2024.03.001-005`，展开时流水号保留三位宽度（001、002、……）；
   - **格式错误**、**区间倒序**（如 `2024.03.008-003`）或**任一侧展开超过 200 个号码**
     都会被拒绝并指出来源行（CSV 侧指出记录号、清单侧指出行号）；
   - 结果按展开后的完整号码列出：**CSV 内重号**与**清单内重号**（含号段交叠，
     附全部来源）、**仅在 CSV** 与**仅在登记清单**中的号码及来源行；
     两侧顺序不同不算差异；
   - 对账**只读**：不改变校样结果、拼版与打印；CSV 或清单任一修改即清空旧结果，
     需重新点击「开始对账」。
12. 右侧实时预览（屏幕上会自动缩放以适应窗口，仅为显示效果）。
13. 点击「打印 / 导出 PDF」，在系统打印对话框中选择打印机或「另存为 PDF」。
   纸张尺寸会被自动设为展签的毫米尺寸，**边距请选择「无 / 默认」**，缩放保持 100%，
   即可得到与预览换行、字号、物理尺寸完全一致的成品。
14. 同款**拼版打印**（单张预览旁的「同款拼版打印」区）：
   - 设置**份数（1～100 的整数）**并选择 **A4 纵向 / 横向**；
   - 仅当所选成品（原稿或修订稿）通过排版校验时才会生成拼版，否则拼版打印保持禁用；
   - 按 A4 纸**每边 10mm 留白、展签间 4mm 间隔**计算每页行列容量并逐页填充，
     展签按原毫米尺寸复制，**不缩放**；
   - 右侧「同款拼版预览」**分页展示每页每张展签的位置**（页码与本页张数见每页下方标注）；
   - 点击「拼版打印 / 导出 PDF」：打印**只输出拼版页**（不含编辑面板与单张预览），
     纸张已自动设为 A4 对应方向，边距选「无」、缩放 100% 即可；
   - 任一方向连一张展签都放不下时，提示**展签尺寸与纸内可用尺寸**并禁用拼版打印，
     可切换纸张方向或缩小展签尺寸；
   - 各份与单张预览共用同一份断行结果与同一二维码码图，换行和码图完全一致。

## 排版规则

1. **实际字宽**：所有字符宽度由 Canvas `measureText` 按当前字号、字体实测（带缓存），
   不是按“汉字全角、英文半角”的假设估算。
2. **英文单词不可拆**：连续拉丁字母/数字（含词内连字符、撇号，如 `state-of-the-art`、`don't`）
   作为整体移动到下一行。
3. **标点避头尾（kinsoku）**：
   - 闭标点（`。，、！？：；）》】”’…—·` 等）不出现在行首；
   - 开标点（`（《【「“‘` 等）不留在行尾；
   - 成对破折号、省略号不会被拆到两行。
4. **中文专名保护**：保护表每行一个词（≤20 个、每个 1～12 个 Unicode 字符，
   空行忽略、重复去重、含换行以外空白的行报错）。标题与中文正文在每个段落内
   **从左到右**识别保护词：同一位置优先最长词、同长按录入顺序，已匹配字符不再参与匹配。
   命中区间**不改变分词、不切分任何 token**，而是把其覆盖到的全部原 token（含只被
   部分覆盖的英文单词、跨词命中的相邻 token）标记为一个**不可断行组**：原英文单词的
   不可断约束与保护区间约束共同生效，绝不新增单词内部断点；组与组相邻/重叠时自动合并。
   标点避头尾按不可断整体的**实际首字符（行首）/尾字符（行尾）**判断，组内部括号不影响
   合法断点；破折号、省略号的成对约束在整体边界继续生效。不可断整体宽度超出行宽时
   与第 5/6 条动态规划、字号枚举统一报失败。匹配不跨段落、不跨空格；英文译文不应用保护表；
   原稿与修订稿分别应用同一张表。
5. **全局最优断行**：动态规划枚举全部可行断点，在所有放得进行宽的排法中
   **最小化非末行空白宽度的平方和**（与 TeX 段落断行思想一致），使各非末行尽量均匀填满；
   代价相同时取行数更少的排法。
6. **字号选择**：正文字号从 **24px 向下枚举到 12px**，取能同时满足行宽与总高度的
   **最大整数**；标题字号固定为正文的 1.4 倍、加粗，并按同样规则折行。
   **双栏模式**下标题横跨整签（按内容全宽折行），中英两栏按扣除 6mm 栏间距后
   **平分得到的实际栏宽各自独立断行**；字号为两栏**共享**——枚举两栏在该字号下
   都能排下（行宽）且总高度（标题 + 较高一栏）不超签高的最大字号。
   **段落对齐**（双栏可选开关）下，中英正文先按换行拆成非空段落并按顺序一一配对：
   两侧段数不等立即失败并指出差异（与字号无关）；段数相等时每段对仍按各自栏宽独立断行，
   但总高度按 `Σ 每段对 max(中文段高, 英文段高) +（段对数−1）× 段间距` 计算，
   因而下一段对在两栏同一高度起始；标题与二维码预留区的核算方式不变，
   12px 仍超高沿用第 8 条报错禁印。
7. **展品介绍二维码**：填写合法链接（`https://` 开头、不含空白/控制字符、
   UTF-8 ≤ 100 字节）后，**先从可用高度中扣除底部 22mm 二维码预留区**，
   再按第 6 条规则为标题与单/双栏正文选最大可容纳字号；原稿与修订稿各自重新核算。
   二维码由内置编码器在浏览器本地生成（字节模式、纠错等级 M、版本 1～10 自动选择、
   八种掩码按 ISO/IEC 18004 罚分自动择优），**不依赖外部二维码服务**；
   18mm 码图在 22mm 预留区内水平居中，四周留白 ≥2mm（内容宽度不足 22mm 时报错禁印）。
   预览与打印共用同一 canvas 码图与同一毫米尺寸。留空链接即不预留、不生成。
8. **装不下即报错**：若 12px 仍超出高度，或存在在最小字号下都放不进行宽的内容
   （例如超长英文单词，或超长保护词），预览区显示红色错误，且**绝不截断、拆词或压缩字号**，
   打印按钮禁用。错误信息会标明问题所在：
   - 超宽：指出是**中文原文栏**还是**英文译文栏**（或标题）及该栏实际栏宽；
     若为保护词超宽，明确给出**该保护词文本及其在 12px 下所需毫米宽度**；
   - 超高：段落对齐模式说明为**中英段对累计高度**超高，其余模式指出**哪一栏较高**，
     并给出内容所需毫米数与可用毫米数；
   - 段数不一致（仅段落对齐模式）：给出**中文、英文各自的非空段落数**及多出几段，
     禁用当前成品打印（可调整回车分段或关闭开关恢复）。
9. **打印一致**：预览的断行结果由同一算法一次性算出并直接写入 DOM（预断行），
   保护词作为预断行中的完整片段写入，预览与打印共用同一份断行结果与毫米尺寸；
   打印时沿用同样的行、同样的 px 字号与毫米容器；`@page` 尺寸在打印前被设置为
   标签宽×高，保证 1px = 1/96 英寸的物理换算一致；保护表更新后实时重排，预览与打印断行相同。
   二维码按同一模块矩阵绘制到每张展签各自持有的 canvas，单张预览与两种拼版的码图一致。
10. **修订对照**：修订稿上限 300 字（按 Unicode 字符计，超出截断）；对齐为码位级
   **最短增删对齐**（仅插入/删除，等价于最长公共子序列），同代价时固定优先保留
   原文较早字符，结果确定唯一；对照仅针对中文正文，标题与英文译文不参与差异计算；
   差异标记只出现在屏幕对照区，打印输出始终只有所选成品版本。
   原稿与修订稿的排版应用同一张中文专名保护表；段落对齐开关对两版**分别生效**——
   各自按自己的中文段落数与共用的英文译文段数配对、各自核算字号与段对高度，
   对照表逐版给出结果（含「段数不一致」），切换成品后预览与打印使用所选版的同一份布局。
11. **同款拼版**：份数 1～100；A4 纵向 210×297mm 或横向 297×210mm，纸张每边留白 10mm，
    相邻展签间隔 4mm；每页容量 = ⌊(可用宽+4)÷(签宽+4)⌋ 列 × ⌊(可用高+4)÷(签高+4)⌋ 行，
    按从左到右、从上到下逐页填充，展签按原毫米尺寸复制、**不缩放**；
    仅当所选成品通过第 8 条校验时生成拼版；任一方向连一张都放不下时，
    给出展签尺寸与纸内可用尺寸并禁用拼版打印；
    每份展签由与单张预览、异款记录共用的构建流程按同一排版结果生成
    （预断行、段落对齐 grid 与 CSS 变量一致），每张持有独立的二维码 canvas、
    按同一模块矩阵绘制，各份换行与码图一致；
    拼版打印时 `@page` 设为 A4 对应方向、只输出拼版页；「打印 / 导出 PDF」仍输出原单张页面。
12. **库存规格选型**：规格表每行「宽×高」（毫米，宽 30～999、高 20～999，最多 12 种；
    空行忽略、重复规格去重、非法行指出行号且不参与推荐，去重后超过 12 种报错不选型）。
    点击「选型」时，以当前选定的成品版本（原稿或修订稿）及当前中英双栏、段落对齐、
    专名保护表与二维码预留设置，对每种规格按第 6 条规则求 12–24px 中的最大可用字号；
    能完整容纳的规格按面积从小到大（同面积按录入顺序）列在前面并给出可用字号，
    其余规格按同一次序列在后面并注明失败原因（超宽/超高/段数不一致/尺寸过小）。
    选型只推荐、不改尺寸：没有可用规格时明确提示且保持当前宽高；
    点击「采用」才把该规格回填宽/高输入并触发重排，预览、单张打印与拼版打印同步刷新。
13. **双语术语核对**：对照表每行「中文术语=英文译名」（分隔符半角 `=` 或全角 `＝`，
    按第一个分隔符拆分、两侧空白忽略；空行忽略；重复中文项、空值、缺少 `=` 的格式错误
    逐行指出行号，存在任一错误即对照表无效并禁用单张与拼版打印）。
    仅在第 6 条「中英段落对齐」开启且中英非空段数一致时，对当前选定成品版本
    （原稿或修订稿）的中文正文与共用的英文译文按段落一一配对逐段核对：
    中文术语在每段内从左到右、同位置最长优先匹配，命中区间不再参与后续匹配（不重复计数）；
    英文译名忽略大小写，按完整词组边界计数（命中两侧不得紧邻第 2 条所述单词字符），
    命中后不重叠地继续计数。逐段比较同一术语两侧出现次数，
    任一术语在某段次数不符即在「双语术语核对」区列出段号、术语及两侧次数，
    并禁用单张与拼版打印；编辑正文/译文/对照表或切换成品版本后随渲染自动重新核对，
    修正后恢复打印。未录入术语、未开启段落对齐或段数不一致时不执行核对
    （段数不一致本身已按第 8 条禁印）。
14. **批量校样**：CSV 首行为表头（须含 `title`、`zh`、`en` 三列，列名去首尾空白、
    忽略大小写，顺序任意，允许额外列），数据记录最多 20 条；字段按 RFC 4180 解析——
    英文双引号包裹的字段可含逗号与换行，字段内两个连续双引号转义为一个，
    引号闭合后只允许空白、逗号、换行或文件尾；行尾兼容 `\n`、`\r\n`、`\r`，
    完全空白的行忽略。逐条校验：列数须与表头一致、标题与中文正文去首尾空白后必填，
    错误定位到记录号（从 1 起、不含表头）；解析失败（如引号未闭合）指出源文本行号
    并整体中止。通过校验的记录仅替换标题、中文正文与英文译文，沿用当前尺寸、
    段落对齐开关、专名保护表、二维码预留与术语对照表，按第 6 条求 12–24px 中
    的最大可用字号并按第 8/13 条门禁（超宽/超高/段数不一致/术语次数）判定；
    结果列出每条可用字号或失败原因。校样不改动任何面板输入与当前成品；
    点击「载入编辑」才回填三栏并清空修订稿，之后等同于手动输入，
    预览、单张与拼版打印随之刷新。
15. **异款批量拼版**：沿用第 14 条批量校样的 CSV 入口与逐条门禁；点击「开始校样」后，
    通过校验的记录按 CSV 原顺序各自经与单张预览共用的构建流程生成展签 DOM
    （各自的预断行、段落对齐 grid 与独立二维码 canvas 原样保留，分页移动后码图不变），
    失败记录不进入拼版；分页按当前展签毫米尺寸、当前纸张方向、
    每边 10mm 留白与 4mm 间隔计算（容量公式同第 11 条），从左到右、从上到下逐页填充，
    不缩放；屏幕预览与打印共用同一份拼版 DOM，逐格对应；单页连一张都放不下时
    给出展签尺寸与纸内可用尺寸并禁用异款拼版打印；修改尺寸、段落对齐、专名、术语、
    二维码或 CSV 后拼版失效，需重新校样，切换纸张方向则立即按新方向重新分页；
    异款拼版打印时 `@page` 设为 A4 对应方向、只输出异款拼版页，
    单张与同款拼版入口不受影响。
16. **馆藏号对账**：沿用第 14 条批量校样的 CSV（表头须含 `accession` 列，列名去首尾
    空白、忽略大小写；对账时各记录 accession 非空，列数不符或号码为空的记录指出
    记录号并中止）与另行粘贴的馆藏登记清单（每行一项，空行忽略，各项去首尾空白）。
    号码严格为「年份（4 位）.批次（2 位）.三位流水号」（如 `2024.03.001`）；
    同前缀闭区间写作 `2024.03.001-005`（终点仅三位流水号），展开时保留三位宽度；
    格式错误、区间倒序逐项拒绝并指出来源行（CSV 侧为记录号、清单侧为行号），
    任一侧展开超过 200 个号码即整体拒绝并指出超限位置。对账按展开后的完整号码
    以集合比较（顺序不同不算差异）：分别列出 CSV 内与清单内的重号（同一号码
    多个来源，含号段交叠，附全部来源）、仅在 CSV 与仅在清单中的号码及来源行，
    各列表按号码升序。对账只读：不修改任何面板输入与校样、拼版、打印状态；
    CSV 或清单任一修改即清空旧结果，需重新点击「开始对账」。

```
        ├── batch.js        # 批量校样：title,zh,en 的 CSV 解析（引号包裹逗号/换行、双引号转义）+ 列数/必填逐条校验（无 DOM 依赖）

        ├── qrcode.js       # 展品介绍链接二维码：字节模式/纠错 M/版本 1–10/掩码择优（无 DOM 依赖）
        └── app.js          # 字宽测量、链接/保护表/术语对照表校验、12–24px 字号搜索、单栏/中英双栏/段落对齐规划、两版对照、术语核对刷新、库存规格选型推荐、批量校样逐条试排与载入编辑、异款批量拼版生成与分页、馆藏号对账（只读）、展签成品 DOM 共用构建（单张预览/同款拼版/异款记录）与渲染、缩放、单张/同款拼版/异款拼版打印
```

## 说明与限制

- 拼版仅支持**同款展签**（同一成品多份）拼到 A4 纸：份数 1～100，纵向/横向可选，
  每边留白 10mm、展签间隔 4mm，按原尺寸逐页填充，不缩放、不旋转展签；
  不同款混排、自定义纸张与裁切线暂不支持；单张打印与拼版打印互不影响。
- 中文专名保护表上限 20 个词、每个 1～12 个 Unicode 字符；保护只作用于**标题与中文正文**，
  英文译文不做专名保护；匹配以段落为界、不跨空格；保护词只保证**整体不断行**，不额外改变字距。
- 库存规格选型最多录入 12 种规格；选型结果基于点击「选型」时的文案与设置计算，
  修改文案或设置后需重新点击「选型」；「采用」前不改变当前尺寸，
  「采用」后等同于手动修改宽高，预览、单张打印与拼版打印随之刷新。
- 批量校样最多 20 条数据记录（不含表头）；CSV 解析失败（如引号未闭合）时整体报错
  并指出源文本行号，列数/必填错误定位到记录号；校样结果基于点击「开始校样」时的
  尺寸与设置（每条记录仅替换标题、中文正文与英文译文，不修改尺寸、段落对齐、
  专名、二维码与术语表），修改设置或文案后需重新校样；「载入编辑」前不改变当前成品，
  「载入编辑」会回填三栏并清空修订稿，之后等同于手动修改，预览、单张打印与拼版打印
  随之刷新；英文译文留空的记录按单栏试排，段落对齐与术语核对仅对填写译文的记录生效。
- 异款批量拼版沿用批量校样的 CSV（最多 20 条记录）：只有通过校样的记录进入拼版，
  失败记录不进入；所有展签使用同一当前尺寸（「异款」指内容不同，非尺寸不同），
  纸张方向沿用「同款拼版」的选择；拼版在点击「开始校样」时生成，之后修改尺寸、
  段落对齐、专名、术语、二维码或 CSV 会使拼版失效，需重新校样；
  切换纸张方向会立即按新方向重新分页。
- 馆藏号对账沿用批量校样的 CSV（同样最多 20 条记录）：表头须含 accession 列且
  各记录非空；号码严格为「年份(4 位).批次(2 位).三位流水号」，区间仅支持同前缀
  简写（如 2024.03.001-005）；任一侧展开上限 200 个号码；对账结果基于点击
  「开始对账」时的 CSV 与清单，任一修改即清空旧结果；对账只读，不参与排版、
  校样、拼版与打印。
- 修订对照只比较中文正文；差异标记仅显示在屏幕对照区，打印输出始终只有所选成品版本。
- 双语术语核对只统计**正文段落**（标题不参与）；术语对照表不设条数上限，但任一录入错误
  （重复中文项、空值、格式错误）都会禁用打印；核对只在段落对齐开启且中英段数一致时执行，
  英文译名按完整词组边界计数（如 `art` 不会命中 `state-of-the-art` 中的 `art`）。
- 展品介绍链接仅支持 `https://` 开头的完整 URL，UTF-8 编码不超过 100 字节、不含空白/控制字符；
  二维码固定占用展签底部 22mm（18mm 码图居中、四周留白 ≥2mm），纠错等级为 M；
  链接内容只用于本地生成码图，不经过任何外部二维码服务。
- 双栏模式仅由**英文译文是否填写**控制：标题不随译文翻译，始终横跨整签；
  两栏共用同一正文字号与行高，不各自缩放；栏间距固定 6mm，暂不提供可调分隔线。
  勾选「中英段落对齐」后两栏改为按段配对、同高起始（段对高度取双方较高者），
  两侧段数必须一致，否则禁用打印并指出段数差异；取消勾选即恢复独立双栏。
- 对齐方式为左对齐（展签常见排版），不做两端对齐拉伸字距。
- 字体使用浏览器/系统自带的宋体/衬线字体族，无需联网下载字体；
  不同系统的字宽可能有细微差别，断行会在打开页面的那台机器上按其可用字体实测计算，
  因此请在实际打印的机器上进行最终预览确认。
- 全部计算在本地浏览器完成，不向任何外部服务发送内容。
